## TrustGraph
TrustGraph is an AI-powered credit scoring system that transforms a developer’s GitHub activity into a measurable financial trust score.  
It analyzes real-time GitHub data such as repositories, followers, stars, and contributions to evaluate credibility, risk level, and loan eligibility — enabling alternative credit assessment for the digital workforce
> "Your code is your credit.”

## Key Features
- Real-time GitHub profile analysis  
- AI-based trust score calculation  
- Loan eligibility estimation  
- Risk classification (Low / Medium / High)  
- Fast response using caching

## Tech Stack
- Frontend: React (Vite), Tailwind CSS  
- Backend: Node.js, Express.js  
- API: GitHub REST API   
- Deployment: Render (Backend), Vercel (Frontend)
